Bhoot

The people who left your repo, and the code of theirs that still runs.

Open live app Source

What it does

Bhoot reads a repository’s git history and writes a remembrance for the people who moved on and the files that died. A local Gemma writes it and git vouches for every claim.

Worth knowing

  • Example: TJ Holowaychuk left Express in 2014, 6,483 of his lines still run
  • Finds deleted files and the reason they went
  • Claims are checked against git
