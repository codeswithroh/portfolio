Tastemaker

A skill that stops coding agents shipping the same indigo gradient.

Open live app Source

What it does

Tastemaker is a skill for coding agents, with native support for Claude Code, Windsurf and Gemini CLI. It grounds generated UI in real reference images and remembers per-developer taste, so the tenth screen matches the first.

Worth knowing

  • Extracts palettes from reference images with a script, not a text summary of the vibe
  • Keeps a style lock per project and a taste profile per developer
  • Plain Markdown and Python: no backend, no account, no API key
