About Rohit

I’m an AI engineer and developer advocate from India. Online I’m codeswithroh.

I build products fast and in public: 65 public repos so far in 2026, across agent tools, on-device AI and onchain apps. My most used project is Tastemaker, a skill that stops coding agents shipping the same generic UI. It has 509 GitHub stars and 53 forks.

One idea runs through most of it: software should check its own work. In Pakka and Baad Mein the model reads and code verifies. In MergePay and Handshake the contract checks the work before money moves. In Bhoot, git vouches for every claim. Models are good enough to act now, and the useful question is who verifies them.

By day I’m a Developer Relations Engineer at BlokCapital, where I write the docs, SDK guides and reference code that get outside developers to a first integration. Before that I built neobanking backends at Orbitxpay and frontends at Metaborong.

I also make videos. I write, film, edit and post them myself, and you can see six of them here. Lately I’ve been drawn to small tools for real people, like Chithi, which reads bills aloud for my family in Bengali, and Pakka, which turns a home baker’s WhatsApp orders into a bake sheet.
